# Changelog

All notable changes to Firn are documented in this file.

## v0.7.0

- **Track 1 — True Auto-Freeze, macOS Memory Pressure Guard & Worktree Orphan Cleanup**:
  - **True Idle Tracking (`guest/firn-guestd/reaper.go`, `Sources/firnd/`)**: Parsed Linux `/proc/<pid>/net/{tcp,tcp6}` little-endian sockets (including IPv4-mapped `::ffff:`) to exclude intra-project container meshes, loopback, and unspecified sockets (`countExternalEstablishedSockets`), replaced byte-counter chatter triggers with a `250,000 usec/s` (25% of 1 core) sustained CPU threshold, wired host-authoritative proxy/`utun`/port activity syncing (`POST /activity`), and filtered Docker `HEALTHCHECK` `exec_start` events from `StreamContainerEventsDetailed` / `WatchDockerEvents` so periodic healthchecks neither reset `hostTouchedAt` nor thrash `inspectCache`. Live verification confirmed idle Compose stacks advance cleanly (`83.9s`, `86.2s`, `195.4s`) while actively host-connected stacks (`established=27–29`) remain at `0.0s`.
  - **macOS Memory Pressure Guard ([`MemoryPressureGuard.swift`](./Sources/firnd/MemoryPressureGuard.swift))**: Responds to kernel `DISPATCH_SOURCE_TYPE_MEMORYPRESSURE` (`warning` 60s cooldown, `critical` 20s cooldown) plus manual `POST /memory-pressure/reclaim` by freezing and reclaiming orphaned stacks first, then idlest Compose stacks, and shrinking the VM balloon (`balloonTarget` shrunk `8.24 GB -> 3.79 GB`; auto-triggered live on `warning` pressure freezing orphaned `northbrio-dev-b8f808112f17` from `461.1 MiB -> 13.7 MiB` RSS/resident RAM).
  - **Orphaned Compose Stack Management (`firn stacks`, `POST /projects/<name>/remove`, `POST /stacks/prune`)**: Detects stacks whose `com.docker.compose.project.working_dir` no longer exists on macOS (`[orphaned]` badges in CLI & `FirnBar`), with dry-run inspection and one-click/targeted cleanup (`firn-orphan-v070` E2E verified `removedContainers=1, removedNetworks=1, orphan_leftovers=0`).
- **Track 2 — Performance Ceilings & Operational Reliability**:
  - **Zero-Copy Vsock & Socket Tuning ([`vsock_splice_linux.go`](./guest/firn-guestd/vsock_splice_linux.go), [`VsockBridge.swift`](./Sources/firnd/VsockBridge.swift))**: Added Linux `splice(2)` with atomic fallback + lossless pipe drain, reusable `IOThreadPool` (32 warm idle workers), `2 MiB` pooled buffers, `512` listen backlogs, and `8M`/`4M`/`2M`/`1M` socket buffers. Under concurrent 33-container workstation load, raw 128 MiB TCP reached **`648.2 MiB/s` median (`880.5 MiB/s` peak)** host→container (`435.2 MiB/s` loaded v0.6.0) and **`457.3 MiB/s` median (`560.5 MiB/s` peak)** container→host (`94.8 MiB/s` loaded v0.6.0, **`4.8×` faster**).
  - **Control-Plane & Status Acceleration ([`reaper.go`](./guest/firn-guestd/reaper.go), [`HostClient.swift`](./Sources/FirnCore/HostClient.swift))**: Added 8-worker container inspect caching (`60s` TTL, invalidated on non-healthcheck Docker events), `10s` VM XPC PID metrics caching, and non-blocking singleflight cached `/disk/usage` (`150ms` initial wait + `45s` `dfClient` + `--refresh`). Cut live `firn status` from `2,488.7 ms` to **`52.2 ms` median** (**`47.7×` faster**), `docker version` from `485.4 ms` to **`28.9 ms`** (**`16.8×` faster**), `docker.sock` `/_ping` from `242.9 ms` to **`9.1 ms`** (**`26.7×` faster**), and `firn disk usage` from `>35s` to **`175.5 ms` fast-path / `18.4 ms` warm cached**.
  - **Guest Block, Mount & Sysctl Tuning ([`guest/init`](./guest/init), [`guest/build-rootfs.sh`](./guest/build-rootfs.sh))**: Replaced dual bind-mounted Docker roots with `"data-root": "/var/lib/firn/docker"` + symlink `/var/lib/docker` (halving guest `/proc/mounts` `overlay` entries from `94` to `45` and total mounts from `159` to `107`), configured `/dev/vdb` `scheduler=none`, `read_ahead_kb=1024`, `commit=60,barrier=0` (`diskSync=none` via `firn.disksync=`), and `32 MiB` TCP sysctls. Boosted 256 MiB `conv=fsync` sequential volume write to **`1,428–1,700 MiB/s` (`0.151–0.179s`, `1.4–1.7 GB/s` in `dd`)** vs `962.4 MiB/s` in v0.6.0 (`2.2 GB/s` sequential read).
  - **Daemon Lifecycle, Origin Detection & Fallback Hardening ([`Distribution.swift`](./Sources/FirnCore/Distribution.swift), [`Config.swift`](./Sources/FirnCore/Config.swift), [`HostNetSupervisor.swift`](./Sources/firnd/HostNetSupervisor.swift), [`Sources/firnd/main.swift`](./Sources/firnd/main.swift))**: Fixed `_NSGetExecutablePath` install-origin detection (`standalone (/Users/zxzinn/.local/bin)`), added atomic `O_EXLOCK | O_NONBLOCK` singleton lock (`firnd.lock`, clean exit `0` if already running), serialized `shutdownVMAndExit` to stop host listeners and `firn-hostnet` before `/poweroff` waiting (with LaunchAgent `ExitTimeOut=20`), reaped stale `firn-hostnet` processes on startup (`firn-hostnet.pid` + `ps` control-sock match), and initialized `HostNetSupervisor` before `VZMachineRunner` so VZ NAT fallback is consistent.
- **Track 3 — Instant Volume Snapshots & OCI Registry Pull-Through Cache**:
  - **Volume Snapshot & Clone ([`volumes.go`](./guest/firn-guestd/volumes.go), `firn volume`)**: Parallel 8-worker CoW `FICLONE` / `copy_file_range` snapshots (`/var/lib/firn/snapshots`) and volume clones with optional `--quiesce`, `/volumes/*` API, and `FirnBar` Disk submenu. Verified `50.0 MiB` snapshot in **`37.8 ms`** and clone in **`96.3 ms`** (`copy_file_range`) with 100% SHA-256 parity and write isolation.
  - **Built-In OCI Registry Pull-Through Cache ([`registry_cache.go`](./guest/firn-guestd/registry_cache.go), `firn cache`)**: Native Go OCI v2 mirror on `127.0.0.1:5000` (`/var/lib/firn/registry-cache`) shared by `dockerd` (`registry-mirrors`) and `k3s` (`registries.yaml`) with Bearer auth caching, SHA-256 verified blob caching, singleflight dedup, 5m tag TTL + offline stale fallback, and LRU eviction. Verified `busybox:1.36.1-musl` pull accelerated from **`4,912.8 ms`** cold to **`1,209.3 ms`** cached (**`4.06×` faster**, `hits=4`, `savedBytes=905,288`).
- **Control Center UI, Brand Identity & Distroless Container Shell**:
  - **Graphite Pro Liquid Glass Control Center ([`FirnControlCenterView.swift`](./Sources/FirnBar/FirnControlCenterView.swift), [`CommandPaletteView.swift`](./Sources/FirnBar/CommandPaletteView.swift), [`LiquidGlassStyle.swift`](./Sources/FirnBar/LiquidGlassStyle.swift))**: Added a 7-section native SwiftUI desktop Control Center (`Overview`, `Stacks`, `Volumes`, `Registry`, `Kubernetes`, `Machines`, `Network & Settings`) inside `Firn.app` using macOS 26+ native Liquid Glass (with `.ultraThinMaterial` fallback on macOS 14/15), system-adaptive Light/Dark Graphite Pro styling, a `⌘K` Command Palette (`CommandPaletteView`), native macOS menu shortcuts (`⌘1`–`⌘7`, `⌘R`, `⌘K`), per-stack RAM history sparklines, and live Cobalt/Amber telemetry sparklines alongside the Menu Bar quick monitor.
  - **Layered Strata Pure-SVG Brand ([`assets/brand/`](./assets/brand/), [`FirnBrandMark.swift`](./Sources/FirnBar/FirnBrandMark.swift))**: Created pure-SVG Layered Strata vector logo & monochrome template assets (`firn-logo.svg`, `firn-mark.svg`, `firn-mark-template.svg`, `AppIcon.icns`, `FirnIcon.png`) and native SwiftUI/CoreGraphics vector marks for the Control Center and Menu Bar.
  - **Smart Container Shell & Distroless Debug Fallback ([`FirnStore.swift`](./Sources/FirnBar/FirnStore.swift), [`Sources/firn/main.swift`](./Sources/firn/main.swift))**: Container **Shell** now probes `/bin/bash` → `/bin/sh` → `/bin/ash` → `/busybox/sh` and automatically opens an interactive `firn shell -t` `nsenter` debug shell (guest `bash`, `curl`, `ip`, `ss`, `ps`, `$FIRN_CONTAINER_ROOT`) when attaching to distroless or scratch images without a shell.

## v0.6.0

- **`firnfs` v3 Kernel `inotify` HMR Forwarding, Gateway Compatibility & Extra Host Mounts**:
  - Upgraded `firnfs` (`guest/firn-guestd/firnfs_linux.go`) with a single-OS-thread (`runtime.LockOSThread` + `syscall.Gettid()`) synthetic VFS notification worker fed by host `FSEvents` and direct host APFS `fsOpLookup` verification: container processes watching bind mounts receive native Linux kernel `IN_CREATE`, `IN_MODIFY`, `IN_CLOSE_WRITE`, `IN_DELETE`, and `IN_ISDIR` events (verified end-to-end with byte-for-byte host/container SHA-256 integrity and zero host file mutation via `FOPEN_DIRECT_IO`), enabling out-of-the-box HMR for Vite, Next.js, Chokidar, and Turbo.
  - Added automatic `firnFSClient` background reconnection (`scheduleReconnect`) across `firn hibernate` / `firn resume` so live `FSEvents` invalidations recover automatically (`firnfsClients >= 1`).
  - Resolved `host.docker.internal`, `host.firn.internal`, and `gateway.docker.internal` to `10.89.0.1` in both `/etc/hosts` and guest DNS (`proxy_relay.go`), plus set `"host-gateway-ip": "10.89.0.1"` in `/etc/docker/daemon.json`.
  - Added configurable additional VirtioFS host shares (`extraMounts` / `firn.mounts=` kernel cmdline / `firn mount <list|add|remove>`).
- **Zero-Config Kubernetes (`firn k8s`) Local Dev Loop**:
  - Added automatic ClusterIP Service & Ingress discovery (`<svc>.<ns>.k8s.<domain>`, `<svc>.k8s.<domain>`, and Ingress hosts under `.k8s.<domain>`) into `ReaperEngine` topology and `ProxyManager`, with `iptables` `FORWARD` + `POSTROUTING MASQUERADE` rules for `10.89.0.1 -> 10.42.0.0/16 & 10.43.0.0/16` so `https://*.k8s.firn.local:8443` reaches k3s pods cleanly while keeping `*.k8s.*` loopback-proxied when `directRouteDNS` is active.
  - Fixed `extraDNSFn` re-entrant `ReaperEngine.mu` deadlock on k3s startup and separated host UI vs guest `/topology?since=` version tracking in `AutoThawProxy`.
  - Added `firn k8s services` and `firn k8s load <image...>` (`docker save | k3s ctr -n k8s.io images import -`).
- **Buildx Rosetta, Machine Clone, Disk Ops & Lifecycle Tuning**:
  - Added `firn buildx <status|setup|remove>` configuring `firn-builder` (`docker-container` driver for `linux/arm64,linux/amd64` using Apple Rosetta), `firn machine clone <src> <dst>` (commits container image and copies `-home` volume), `firn socket <status|link|unlink>`, `/system/df` Docker breakdown (`images`/`containers`/`volumes`/`buildCache`/`reclaimable`), and `POST /disk/prune` (`firn disk prune [--all]`).
  - Enabled `CapabilityRXChecksumOffload` + `4 MiB` socket/TCP buffers (`1 MiB` pool) in `firn-hostnet`, `32/16 MiB` `SO_VM_SOCKETS_BUFFER` attempts (`2 MiB` pool) in `firn-guestd`, `40ms` Docker event burst coalescing (`1,690.78 ms` 3-service Compose `down -v`), `BalloonController.convergeAfterResume()` (`+0.35s` & `+2.5s`), and background idle `fstrim` (`autoTrimMinutes`, default `60`).
- **Control Center (`FirnBar`) & Automated E2E Regression Suite (`make e2e`)**:

## v0.5.0

- **`firnfs` v2 (Depth-2 Streaming Prefetch, `FOPEN_CACHE_DIR` & 150ms Self-Echo Filter)**:
  - Upgraded `firn-hostnet` (`fsOpPushPrefetch = 0x81`) to stream up to 64 child subdirectories (Depth-2, bounded by 2,048 files / 8 MiB / 2 concurrent slots) asynchronously in the background after parent directory opens, bypassing noise directories (`.git`, `node_modules`, `.cache`, `.build`, `target`, `__pycache__`, `.venv`).
  - Replaced FUSE `n.Path()` tree-lock walks with `renameEpoch`-checked `cachedRel` paths, added `RLock` read fast-paths (`GetEntry`, `GetDirPrefetch`), `childrenByParent` subtree indexing for O(1)/O(subtree) targeted invalidation, negative cache lookups (`IsKnownAbsent`), local `lstatLinuxAttr` / `fstatLinuxAttr` stat fast-paths, `FOPEN_CACHE_DIR | FOPEN_KEEP_CACHE`, `FOPEN_NOFLUSH` on read-only opens, `EnableSymlinkCaching`, and `150ms` `recentLocalMut` self-echo suppression on `FSEvents`.
  - Live M5 Max benchmark (concurrent host load `20.7–32.6`) cut 1,000-file cold tree walk from `849.5 ms` (v0.4.0) to **`365.21–423.28 ms`** (`2.0–2.3×` faster than v0.4.0, vs `3,020.81 ms` cold / `1,181.61 ms` med on same-moment OrbStack), **`98.37–98.51 ms`** in-container reads, and **`266.72 ms`** (`570.06 ms` wall) for `500 × 4 KiB` create+write+remove (`383.6 ms` / `759.6 ms` wall in v0.4.0).
- **Pooled `1 MiB` Vsock Streaming & Session-Safe Auto-Hibernate**:
  - Replaced per-connection buffer allocation in `VsockBridge` and `AutoThawProxy` with a page-aligned `1 MiB` `StreamBufferPool`, raised guest `SO_VM_SOCKETS_BUFFER` windows (`16 MiB` max / `8 MiB` target), and tracked `activeSessionCount` across both proxies.
  - Guarded automatic hibernation on zero active vsock/auto-thaw sessions, added `firn up --hibernate-seconds N`, and eliminated the `_hibernating` / `saveMachineStateTo` race in `VZMachineRunner`. Live M5 Max tests under heavy host load (`21–32`) reached **`6,950.3 req/s`** HTTP/1.1 Keep-Alive (`p50 2.032 ms`, `+33.7%` over v0.4.0), **`4,454.2 req/s`** HTTP conn/req, **`2.51 ms`** (`3,678.9 req/s`) on `:8443` HTTPS, **`0.132 / 0.129 / 0.159 ms`** PG RTT, **`5,169.9 MiB/s`** Volume seq read, **`27.71 ms` HTTPS / `29.68 ms` TCP** Auto-Thaw, **`759.6 MiB -> 20.3 MiB`** snapshot hibernate, and **`1,467.3 ms`** resume.
- **Zero-Dependency Distribution, Installation & Self-Update**:
  - Added [`scripts/install.sh`](./scripts/install.sh) zero-dependency curl installer (`bash <(curl ...)` style), `firn images <status|pull [--version vX.Y.Z] [--force]>`, and automatic guest-image download + atomic native Swift `120 GiB` sparse `~/.firn/data.ext4` creation on `firn up` (`--no-pull` opts out).
  - Switched GitHub Release archives from `zstd` to GNU `tar --format=posix --sparse -czf` (natively extractable on stock macOS without Homebrew `zstd`), added automated Homebrew formula (`firn.rb`) output in `.github/workflows/release.yml`, and fixed CI Go cache discovery across rootless subdirectories.
  - Hardened `firn upgrade` with semver comparison, Homebrew Cellar detection, pre-stop SHA-256 verification of both macOS and Linux archives, `codesign` virtualization entitlement verification/re-signing on `firnd`, `.bak` rollback on swap failure, guest-image upgrades preserving `data.ext4`, and automatic `firnd` restart; added non-blocking GitHub Release update checks (`"Check for Updates…"`) in `FirnBar`.

## v0.4.0

- **Hybrid `firnfs` (`AF_VSOCK:2385` + `FSEvents` Push Invalidation)**: Added a 64 MiB FUSE read/metadata cache fed by 16-worker `OP_READDIR_PREFETCH` RPCs over `AF_VSOCK:2385` and live macOS `FSEvents` invalidation, cutting 1,000-file bind-mount reads from `407.2 ms` to **`78.0 ms`** (`5.2×` faster) while passing writes/creates straight through `/mnt/virtiofs-home` (`383.6 ms` for 500 creates+writes+unlinks).
- **2-Thread Full-Duplex `AF_VSOCK` + `firn-hostnet` Jumbo Engine**:
  - Replaced single-threaded `poll()` vsock splicing with dual-thread `1 MiB` full-duplex streaming and `8 MiB` `SO_VM_SOCKETS_BUFFER` windows, boosting 128 MiB raw TCP throughput to **`921.4 / 969.0 MiB/s`**, PostgreSQL `SELECT 1` RTT to **`0.136 ms`**, PG bulk queries to **`398.3 MiB/s`**, and HTTP/1.1 Keep-Alive to **`5,197.8 req/s`**.
  - Added standalone Go `firn-hostnet` L2/L3 gVisor engine on connected `AF_UNIX SOCK_DGRAM` `MTU 16384` (`VZFileHandleNetworkDeviceAttachment`, zero `vmenet*`), concurrent `:8443` HTTPS proxy with dynamic in-memory TLS leaf certs (**`3.05 ms`**, **`2,981.8 req/s`**), `1.81 MiB/s` outbound egress, default `diskSyncMode="none"`, and `"userland-proxy": false`.
- **APFS VM Hibernation (`firn hibernate` / `firn resume`)**: Added `VMBackend` abstraction + `VZVirtualMachine.saveMachineStateTo` / `restoreMachineStateFrom` (`vm-state.vzvmsave`), dropping host footprint from `777.3 MiB` to **`21.4 MiB`** (`0 MiB` VM XPC footprint) with transparent auto-wake on incoming Docker or HTTP/HTTPS requests.
- **Built-In Kubernetes (`firn k8s`) & Multi-Distro Linux Machines (`firn machine`)**: Added single-node `k3s` (`v1.31.6+k3s1`) management with safe kubeconfig merging (preserving existing `current-context` unless `--use`) and persistent `ubuntu`/`debian`/`alpine`/`arch`/`fedora` environments sharing `$HOME` and `<name>.firn.local` DNS.
- **Opt-In Nested Virtualization (`--nested-kvm`), `utun` Direct Routing & Metal/Vulkan GPU**: Added `firn up --nested-kvm` exposing `/dev/kvm`, optional `firn route` direct host routing (`10.87.0.0/24`, `10.88.0.0/16`), and `KrunMachineRunner` (`--backend krun --gpu`) with Metal/krunkit VirtIO-GPU Venus detection.
- **UI, Packaging & Release Automation**: Added 60-sample CoreGraphics sparklines and live streaming container/machine logs in `FirnBar`, expanded Settings UI, Homebrew formula (`packaging/homebrew/firn.rb`), GitHub Release workflow (`.github/workflows/release.yml`), and `firn upgrade` with SHA-256 verification.

## v0.3.0

- **Vsock User-Space L3/L4 Netstack (`firn0`)**: Full outbound container TCP/UDP routing over `AF_VSOCK` (`vsock:2380/2381`) using gVisor netstack so container egress works seamlessly alongside macOS VPNs and `vmenet*`-limited hosts.
- **Sub-100ms Target-First Auto-Thaw + Tiered `zram` Swap**: Prioritize unpausing the targeted container first, thaw sibling containers and refresh topology asynchronously, and back cold pages with `zram0` (priority `100`) ahead of disk swapfile (priority `10`).
- **Dual-Stack Loopback Port Forwarding**: Bind both `127.0.0.1` and `[::1]` so dual-stack runtimes (Node.js, Python, curl) never hit IPv6 `ECONNREFUSED` retries.
- **Local HTTPS & Root CA**: Built-in host CA (`firn ca`) and `Network.framework` TLS proxy on `:8443` (`https://*.firn.local`) with optional `/etc/pf.anchors/dev.firn` port 80/443 redirection (`firn https`).
- **Interactive Shell & SSH Agent Forwarding**: `firn shell` PTY over `vsock:2382` (raw TTY + `SIGWINCH` resize) and automatic host `SSH_AUTH_SOCK` forwarding (`vsock:2383`).
- **Disk & Context Tooling**: `firn disk usage`, online `fstrim` (`firn disk trim`), `firn context <use|restore>`, clean `POST /poweroff` + read-only root unmount shutdown, per-project `firn.reaper.idle` label, event-driven `FirnBar` updates with a native Settings panel, and background balloon convergence.
- **Open-Source Readiness**: Apache-2.0 license, CI workflow, issue templates, contributing guide, security policy, and sanitized defaults.
